# 📊 Intelligent Data Assistant

Welcome to your Enterprise Agentic RAG System.

This AI is equipped with a multi-agent workflow capable of:

* Reading Documents: Extracting context from PDFs and Word documents.    
* Analyzing Data: Writing Python code to aggregate and visualize Excel & CSV files.
* Self-Correction: Automatically evaluating its own answers for accuracy.

⚡ How to get started:

1. Click the Paperclip icon 📎 next to the chat box to attach your files.
2. Ask a question about the data, or ask it to generate a summary.
3. Watch the AI route your query to the correct agent in real-time!
